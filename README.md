# Kaomoji

Kaomoji is an Android app for finding kaomoji by tag and copying them into other apps. It's distributed through Google Play.

The APKs under Releases are early builds from before the move to Play and no longer receive updates.

[Privacy policy](PRIVACY.md)

Kaomoji data adapted from [FontVibe](https://fontvibe.ai/tools/kaomoji) (CC BY 4.0).
