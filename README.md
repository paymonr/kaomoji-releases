# Kaomoji

Installable builds of Kaomoji, an Android app for finding kaomoji by tag and copying them into other apps.

**[Download the latest version](https://github.com/paymonr/kaomoji-releases/releases/latest)** (the `.apk` file under Assets). Needs Android 8.0 or later. Open the file on your phone to install it; Android will ask you to allow installs from your browser or file manager.

Once installed, the app checks this page for new versions and offers to update itself.

Kaomoji data adapted from [FontVibe](https://fontvibe.ai/tools/kaomoji) (CC BY 4.0).
